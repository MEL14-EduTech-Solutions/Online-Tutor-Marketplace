# Online Tutor Marketplace

A sample project repository for planning and documenting a solution that helps students connect with verified academic tutors in Melbourne.

## Project Overview
Students often struggle to find qualified tutors that are affordable, safe, and conveniently located for their specific subject needs. This project explores a platform concept that helps students compare tutor options, verify academic credentials through a secure KYC process, and manage lesson bookings efficiently.
